# Puddles

A silly duck who lives in a magic pond on your screen. Kids hold up anything they can find, it pops into the pond as a sticker, and Puddles decides what to do about it.

Under the hood, one fine-tuned small vision-language model (SmolVLM + LoRA) writes Puddles' reactions. It is measured against frontier models on quality, latency and cost. Everything else runs off the shelf, and play is fully offline.

The project is also a demonstration of agent-driven development with enforced quality gates: work is planned as GitHub issues, implemented in small PRs, and merged only through automated checks and review.

Status: bootstrapping.
